# 90 天路线图

## Phase 01: Python 基础与工程习惯

Day 1-15 的重点是把 Python 写熟，尤其是后面做 Agent 必须频繁使用的能力：

- 变量、条件、循环、函数
- 列表、字典、集合、字符串处理
- 文件读写、JSON、CSV
- 模块、包、虚拟环境
- HTTP 请求和简单 CLI
- 测试、异常处理、日志

## Phase 02: LLM 与 OpenAI API

Day 16-30 开始进入大模型应用开发：

- Prompt 基础
- Chat Completions / Responses API 思维
- 结构化输出
- 流式响应
- 多轮上下文
- 简单聊天机器人

## Phase 03: Agent 基础

Day 31-45 关注 Agent 的核心结构：

- 任务拆解
- 工具选择
- 简单记忆
- ReAct 思路
- Agent 循环

## Phase 04: Tools / Function Calling / MCP

Day 46-60 让 Agent 真正能做事：

- Function Calling
- 工具 schema 设计
- 本地工具调用
- MCP 基础
- 外部服务接入

## Phase 05: LangChain / LangGraph

Day 61-75 学习常见 Agent 框架：

- LangChain 基础组件
- LangGraph 状态图
- 多节点工作流
- 错误恢复
- 可观测性

## Phase 06: 完整 Agent 项目

Day 76-90 完成几个可展示项目：

- 简单聊天机器人
- 工具调用 Agent
- RAG Agent
- MCP Agent
- 最终综合 Agent
