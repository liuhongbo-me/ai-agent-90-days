# AI Agent 90 Days

面向资深 Java 后端开发者的 90 天 AI Agent 学习仓库。

这条路线不是从 Python 或深度学习训练开始，而是围绕 Java 后端工程能力展开：LLM API、Spring AI Alibaba、Tool Calling、RAG、MCP、Agent Workflow，最后补最小 Python + LangGraph 生态阅读能力。

## Roadmap

| Phase | Days | Topic | Output |
| --- | --- | --- | --- |
| phase-01-ai-basics | Day 1-7 | AI / LLM 术语扫盲与环境准备 | 概念笔记、第一次模型 API 调用准备 |
| phase-02-java-llm | Day 8-14 | Java 调用模型、Prompt、结构化输出、Streaming | Java 日志分析助手 |
| phase-03-spring-ai | Day 15-21 | Spring AI Alibaba 基础 | Spring AI 工具箱 API |
| phase-04-tool-calling | Day 22-28 | Tool Calling / Function Calling | 运维/业务查询小 Agent |
| phase-05-rag | Day 29-49 | Embedding、向量库、RAG 工程化 | 企业技术文档知识库 |
| phase-06-mcp | Day 50-56 | MCP 原理与 Java MCP Server/Client | Database / Ops MCP Server |
| phase-07-agent-workflow | Day 57-70 | Agent、ReAct、Memory、Workflow、Graph | 多步骤故障分析 Agent |
| phase-08-python-langgraph | Day 71-77 | 最小 Python、FastAPI、LangGraph | Python Agent 示例与 Java 联调 |
| projects | Day 78-90 | 评估、观测、安全、综合作品 | 企业智能运维 Agent |
